## 序文 (Foreword)

本技術仕様書 (TS) は FVC プロジェクトにより作成された。本書は、FVC (以下「本方式」) の符号化ビットストリームの構文、その意味及び規範的な復号処理を規定し、参考として符号器の指針と評価結果を示す。

本書の版番号 V0.9.0 は、参照実装が規範的復号処理のすべてを実装しているが、一部の処理 (附属書 D) が浮動小数点演算に依存しており、実装間の完全なビット一致がまだ保証されていない段階であることを示す。

## 助動詞の用法 (Modal verbs terminology)

本書では、ETSI 起草規則に倣い次の表現を用いる。

| 表現 | 意味 |

## 序論 (Introduction)

本方式は、ブロック変換符号化を中核としつつ、次の要素を一つのビットストリームに統合する。

- YCoCg-R 可逆色変換と CfL 型の色予測
- 余弦変調 PQMF による最大 256 帯域の帯域分解と、帯域画像のブロック符号化
- アフィン図形 (ガウス・楕円・矩形・三角形) の重ね合わせ表現
- 4〜64 画素の四分木ブロック分割、DCT-II / DST-VII / DCT-VIII / 恒等変換
- デッドゾーンスカラ量子化、E8 格子 VQ、利得形状分離 (非線形スカラ量子化・前変換・ランダム投影を含む)
- TNS、ノイズ補完、パラメトリック帯域補完
- I / P / B / COPY フレーム、グローバル動きモデル (並進〜射影)、帯域別ゲイン、FIR 動き、OBMC
- 最大 65536 項目の辞書予測
- デブロック、周波数ゲインフィルタ、画素ゲインマップ、方向性デリンギング (CDEF 型)、適応ループフィルタ (ALF)
- L1 (非可逆) / L2 (残差) の階層による可逆符号化
- 文脈混合 (CM) 確率モデルと 2 値 rANS 算術符号

## 3 定義、記号及び略語

### 3.1 定義

- **ユニット (unit)**: 種別とバイト長で区切られたビットストリームの単位。
- **CTU**: 64×64 画素 (色差平面では色差画素で 64×64) の符号化木単位。
- **葉 (leaf)**: 四分木分割の末端ブロック。予測と残差の単位。
- **有効領域 (valid region)**: 平面の実寸 (w×h)。CTU の倍数へのパディング部を除いた範囲。
- **帯域画像 (band image)**: PQMF 解析で得られる帯域 k の間引き後の 2 次元信号。
- **主ストリーム (main stream)**: フレームごとに 1 本の rANS 符号列。フレーム単位・平面単位の要素を運ぶ。
- **タイルストリーム (tile stream)**: タイルごとの rANS 符号列。ブロック層を運ぶ。
- **POC**: 表示順序番号。

## 4 概要

### 4.1 復号の流れ

1. シーケンスヘッダ (SEQ) を読み、画像形式を得る。
2. フレームユニットごとに、フレームヘッダ、主ストリーム、タイルストリームを取り出す。
3. フレーム種別に応じて参照ピクチャを DPB から選ぶ。
4. 主ストリームからグローバル動き・ゲイン等を復号する (インターのみ)。
5. 平面 (Y/Co/Cg または Y/U/V) ごとに次を行う。
   1. 図形レイヤ (有効時)
   2. 帯域方式か画素ブロック方式かの選択と、各方式の復号
   3. ループ内フィルタ (デブロック → 周波数ゲイン → ゲインマップ → CDEF → ALF)
   4. 可逆層 (L2 または完全可逆)
6. 再構成フレームを DPB に格納し、表示順に出力する。

### 4.2 色空間

シーケンスヘッダの `color_transform` が 0 のとき、復号後の 3 平面は YCoCg-R であり、出力時に逆変換しなければならない。

```
t  = Y − (Cg ≫ 1)
G  = Cg + t
B  = t − (Co ≫ 1)
R  = B + Co
```

`color_transform` が 1 のとき、平面はそのまま出力する。

## 7 エントロピー符号化

### 7.1 2 値 rANS

- 確率の精度は 12 ビット (P1 ∈ [1, 4095]、尺度 4096) とする。
- 状態 x の正規化範囲は [2^23, 2^31) とし、1 バイト単位で再正規化する。
- 符号化は記号列の逆順に行い、最後に状態を 4 バイトで書き出す。符号列は書き出したバイト列を反転したものである。
- 復号器は先頭 4 バイトをビッグエンディアンで x とし、各 2 値記号を次で復号しなければならない。

```
s = x mod 4096
if s < P1: bit = 1; x = P1·(x ≫ 12) + s
else:      bit = 0; x = (4096 − P1)·(x ≫ 12) + s − P1
while x < 2^23: x = (x ≪ 8) | next_byte()   (末尾以降は 0)
```

### 7.2 文脈混合モデル (CM)

各構文要素の群は独立したモデルを持つ。2 値記号は (node, a, b) の 3 つ組で文脈付けされる。

1. **入力**: 4 個のハッシュ表 (各 2^14 項目) から、
   - 表 0: hash(node, 0, 0)
   - 表 1: hash(node, a, 1)
   - 表 2: hash(node, b, 2)
   - 表 3: hash(node, a, b ⊕ 0xABCD)

   の項目を引く。各項目は 2 速度の確率カウンタ (16 ビット、更新率 1/16 と 1/128) で、平均を 12 ビット確率とする。
2. **混合**: 各確率を stretch 領域に写し、バイアス入力 256 を加えた 5 入力を、文脈 (node·31 + (a & 31)) mod 1024 の重みで線形結合し、squash で確率 p_mix に戻す。重みの初期値は 2^16/4、更新は w_i += (st_i · (bit·4096 − p_mix)·6) ≫ 10 とする。
3. **APM**: stretch(p_mix) を 33 区間で補間する表 (文脈 node mod 1024) から p_a を得て、P1 = Clip3(1, 4095, (p_mix + 3·p_a) ≫ 2) とする。表の更新率は 1/64 とする。
4. モデルの表は初回使用時に初期化する。

### 7.3 2 値化

| 名称 | 定義 |
|---|---|
| bit | 1 個の 2 値記号 |
| uint(v) | v+1 の指数 e を node 2..(2+e) の単進で符号化し、仮数の上位 3 ビットを node 64+32e+i で、残りを等確率 (バイパス) で符号化 |
| uintc(v) | uint と同じ指数部。仮数は全ビットを文脈付き (上位 5 ビットは 2 分木位置 node 3000+64e+tree、以降 node 5000+32e+k) |
| sint(v) | node 0 にゼロフラグ、node 1 に符号、続いて uint(|v|−1) |

## 8 フレーム復号処理

### 8.1 参照と DPB

DPB は最大 12 ピクチャを保持する。各ピクチャは再構成画像、輝度動きベクトル場、その参照 POC を保持する。I フレームの復号時、辞書の動的領域を初期化する (`dict_reset`)。

### 8.2 グローバルパラメータ (インターフレーム、主ストリーム)

順に次を復号する。

1. **グローバルモデル**: `gm_type` = uint (0 並進、1 相似、2 アフィン、3 射影)。type ≥1 で a, b (sint, Q16)、type 1 では d = a, c = −b。type ≥2 で c, d。type 3 で h31, h32 (sint, Q24)。各値の絶対値は 32767 以下でなければならない。
2. **並進** t_x, t_y (sint, 1/4 画素、画面中心での値)。
3. 各平面 p について、ゲイン g_p (64 + sint、Q6、0〜256)、オフセット o_p (sint)、高域ゲイン h_p (64 + sint、Q6、0〜128)。

位置 (x, y) の動きベクトルは、画面中心 (c_x, c_y) = (width/2, height/2) を基準に u = x − c_x、v = y − c_y として

```
D  = 1 + h31·u/2^24 + h32·v/2^24          (type 3。その他は 1)
x' = ((1 + a/2^16)·u + (b/2^16)·v + t_x/4) / D
y' = ((c/2^16)·u + (1 + d/2^16)·v + t_y/4) / D
mv = round(4·(x' − u), 4·(y' − v))        (1/4 画素)
```

で与える (type 0 では mv = (t_x, t_y))。

h_p ≠ 64 のとき、L0 先頭参照の平面 p を次で置き換えたものを予測に用いる。L(·) は 3×3 二項フィルタ (重み 1-2-1、端は複製、+8 ≫ 4) である。

```
ref'(x) = Clip(L(ref)(x) + ((h_p · (ref(x) − L(ref)(x)) + 32) ≫ 6))
```

L0 先頭参照には、さらに ゲイン g_p/64 とオフセット o_p を適用する。

### 8.3 COPY フレーム

COPY フレームは残差を持たない。各平面はグローバル予測そのものである。gm_type = 0 では全面を (t_x, t_y) で補償し、それ以外では 8×8 輝度ブロック (色差では対応する大きさ) ごとに、ブロック中心 (x+4, y+4) の mv で補償する。

### 8.4 平面の処理順

平面 0, 1, 2 の順に処理する。各平面は CTU (64) の倍数 W×H にパディングした作業平面で再構成し、出力時に w×h へ切り出す。参照ピクチャは切り出した平面を保持し、範囲外の参照は端の画素で補う。

## 9 ブロック層

### 9.1 タイルと CTU

平面は tile_cols × tile_rows のタイルに CTU 単位で等分割される。各タイルは独立したタイルストリームを持ち、予測の参照はタイル内に限定される。タイル内の CTU はラスタ順、CTU 内のブロックは Z 順 (モートン順) で処理する。

### 9.2 四分木

CTU は max_log2 の大きさの根ブロックに分けられ、各ブロックは split フラグ (bit) で 4 分割される (大きさが min_log2 の場合フラグを持たない)。
**有効領域の外に完全に位置するブロックは符号化されず、構文も持たない。** そのブロックの輝度動き情報は既定値 (イントラ扱い) とする。有効領域をまたぐブロックは通常どおり符号化され、領域外の再構成値は表示されない。ブロック層の後、領域外の画素は最も近い領域内の画素の複製で置き換えなければならない。

参照可能性: 位置 (p_x, p_y) は、同じタイル内かつ有効領域内で、CTU のラスタ順と CTU 内のモートン順において現ブロックより前にあるときに限り参照できる。

### 9.3 葉の構文 (概略)

葉は次の順に構文要素を持つ。

1. インターフレームで `is_inter`。
2. インターの場合:
   - (輝度、rect 有効、s ≥ 8) 分割形状 0: 2N×2N、1: 2N×N、2: N×2N
   - 区画ごとの動き: マージフラグとマージ番号 (切り詰め単進、候補は最大 5)、または明示 (B では方向、参照番号、MVD)
   - (firb 有効、s ≥ 16) FIR 動き基底フラグと ψ0..3 (sint、|ψ| ≤ 16)、(s ≤ 32) 係数バンド利得フラグと a0..2 (8 + sint、0〜16)
3. 帯域方式内の場合: 帯域間/時間方向予測 (pt = 4)、帯域源、利得。
4. 辞書が有効で s ∈ {8, 16}: 辞書フラグ、番号、利得。
5. それ以外 (イントラ): IBC フラグとブロックベクトル、またはイントラモード (9.4)、色差では CfL の α。
6. `cbf`。0 のとき、条件を満たせばノイズ置換の強さ (0〜7)。
7. `cbf` = 1 のとき: MTS 番号 (輝度、s ≤ 32)、量子化方式 (`qmode`: 0 スカラ、1 E8、2 利得形状)、TNS (s ≥ 8 かつ qmode ≠ 2)、係数 (11.4)、ノイズ補完の強さ (0〜3)。

### 9.4 イントラモード

モード番号は 0: DC、1: Planar、2〜34: 角度 (HEVC と同じ番号)、35: CfL (色差のみ)、36: Smooth、37: Paeth とする。全角度モード時は 6 候補の MPM を用いる。

```
MPM = [左, 上, Planar, DC, 左±1, 上±1 (角度のとき), 垂直, 水平, 2, 18, Smooth, Paeth] から重複を除いた先頭 6 個
```

`is_mpm` が 1 のとき候補番号を切り詰め単進で、0 のとき残り 31 モードを 5 ビットの 2 分木で符号化する。参照画素は上・左・右上・左下を用い、参照可能性は 9.2 による。

## 10 予測

### 10.1 イントラ

- 角度予測は HEVC 型の 1/32 画素補間とし、参照画素に平滑化を施す。
- Smooth は上・左の両端からの 2 次元補間、Paeth は左・上・左上から最近傍を選ぶ。
- CfL: 色差予測 = DC + α·(縮小輝度 − 平均)。

### 10.2 インター

- 動きベクトルは輝度 1/4 画素単位。輝度は 8 タップ DCT-IF、4:2:0 色差は 1/8 画素で 4 タップ補間とする。
- ψ > 0 のとき 3×3 分離平滑 [a, 1−2a, a]、a = ψ/16 を補償後に適用する。
- 双予測は 2 予測の平均とする。
- マージ候補: 左、上、時間方向 (同位置ピクチャの動きを POC 距離で拡縮)、左上、グローバル (ブロック中心での gm の mv)、ゼロ。
- MV 予測子: 左、上、時間方向、グローバル (ブロック位置での gm の mv) の順。
- 色差の動き情報は送らず、輝度の 4×4 動き場から導出する。輝度がイントラの位置では近傍 (最大 16 画素) のインター動きを借りる。
- **FIR 動き基底** (firb): P′ = P + (ψ0·∂x P + ψ1·∂y P + ψ2·∂xx P + ψ3·∂yy P)/16。差分はブロック内で端を複製する。
- **係数バンド利得** (§7.6-2): P の DCT 係数を u+v < s/4、< s/2、それ以外の 3 バンドに分け、a_b/8 倍して逆変換する。
- **OBMC**: 上・左の符号化済みインター近傍の動きが現ブロックと異なるとき、その動きによる予測を境界から ov = min(s/2, 16) 画素まで重ねる。重み (64 分率) は次の表による。

| ov | 近傍予測の重み w_i (i = 境界からの距離) |
|---|---|
| 4 | 31, 22, 10, 1 |
| 8 | 32, 29, 25, 19, 13, 7, 3, 0 |
| 16 | 32, 31, 30, 28, 26, 24, 21, 18, 14, 11, 8, 6, 4, 2, 1, 0 |

  P ← (P·(64 − w_i) + P_nb·w_i + 32) ≫ 6

### 10.3 IBC と辞書

- IBC: 同じフレームの符号化済み領域からのブロックコピー。ブロックベクトルは予測子との差分で送る。
- 辞書: 予測 = DC 予測 + (g · D_id + 8) ≫ 4、|g| ≤ 64。辞書は最大 65536 項目 (予約 4096)。各フレームの終わりに、符号器が選んだ再構成ブロックを ADD_FROM_RECON で追加する (先入れ先出しで置換)。

## 11 変換と量子化

### 11.1 変換

正規直交の DCT-II、DST-VII、DCT-VIII 及び恒等変換を用いる。MTS 番号 m に対する (水平, 垂直) の組は次の表による (m = 0 は DCT-II)。

| m | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 水平 | DST7 | DCT8 | DST7 | DCT8 | DST7 | DCT2 | IDTX | DCT2 |
| 垂直 | DST7 | DST7 | DCT8 | DCT8 | DCT2 | DST7 | IDTX | DCT8 |

m = 5〜8 は s ≤ 16 でのみ用いる。

**逆変換は整数演算で行わなければならない。** 係数を Q8 (×256 の丸め) の整数とし、基底行列の各要素を round(T·2^14) の整数とする。縦、横の順に積和を計算し、各段で (acc + 2^13) ≫ 14 とする。出力は Q8 の値を 256 で割ったもの (画素の丸め前) である。

### 11.2 量子化ステップ

```
e = qp − 4;  q = ⌊e/6⌋;  r = e − 6q
Δ(qp) = K[r] · 2^q · 2^(bit_depth − 8)
K = {1, 1.122462048309373, 1.2599210498948732, 1.4142135623730951, 1.5874010519681994, 1.7817974362806785}
```

色差の qp は Clip3(0, 63, qp + cqp_off)。aqp が有効なとき、CTU ごとに dqp (sint、−12〜12) を送り、qp + dqp を用いる。

### 11.3 係数の走査

係数は対角走査 (左下から右上への反対角線の列) で 1 次元化する。

### 11.4 係数の符号化

- **qmode 0 (スカラ)**: `last` (uintc) は走査順で最後の非ゼロ位置。0..last の各係数を sint で符号化する。文脈は周辺の符号化済み係数 (2D テンプレート)、ブロックの大きさ、DC か否か、帯域間・変化マスク文脈とする。最後の係数は |v|−1 と符号で符号化する。再構成は q·Δ。
- **qmode 1 (E8 格子 VQ)**: 8 係数ずつの組 (チャンク数を uintc) を E8 格子点で表し、コセットビットと 8 個の整数を送る。再構成は (格子点/2)·Δ。
- **qmode 2 (利得形状)**: 箇条 11.6。
- **TNS**: 走査順の係数列に次数 1〜8 の格子フィルタを適用する (PARCOR を 4 ビット、|k| ≤ 7)。
- **ノイズ補完**: last 以降に振幅 nf/8·Δ の擬似乱数 (±) を置く。

### 11.5 MTS 番号の構文

非ゼロフラグ、(s ≤ 16 のとき) 拡張フラグ、2 ビット (2 分木) の順に符号化する。

### 11.6 利得形状符号化 (gs)

- **配置**: DC を除く係数を、放射周波数 ρ = √(u²+v²) のオクターブ帯 b = 1 + ⌊log2 ρ⌋ に分け、帯ごとに走査順で長さ 16 以下のパーティションに区切る。
- **構文**: dc (sint)、使用パーティション数 (uintc)、各パーティションのモード (0 ゼロ、1 形状量子化、2 ノイズ置換、3 符号のみ、4 コピー、5 包絡補間)。
- **利得**: g = 2^(qg/4)。qg は「同じ帯の直前の利得 → 直前ブロックの同じ帯の利得 → 直前の利得 → 8」の順で得た予測値との差分を sint で送る (§5.3 連結)。モード 5 の利得は直前 2 個からの対数線形外挿で、送らない。
- **形状量子化 (モード 1)**: 利得フラグ gon (0 のとき量子化値をそのまま使う)、量子化器 type (0 非線形スカラ + 前変換、1 E8、2 ランダム投影 (16→8))、type 0 の前変換 pn (0 恒等、1 べき 0.75 (非線形スカラ量子化器)、2 べき 0.6、3 asinh、4 符号付き対数、5 区分線形)、シンボル列。
- **コピー (モード 4)**: 並び替え Π (恒等、反転、半周巡回、偶奇交換) と、コピー元 (直前から 1〜4 個目の非ゼロパーティション)。
- **再構成**: モード 1〜4 は形状を ĝ にエネルギー正規化する (gon = 0 を除く)。ノイズは SplitMix64 による一様乱数とする。

## 12 帯域 (PQMF) 符号化

### 12.1 フィルタバンク

余弦変調 PQMF の原型は Kaiser 窓低域通過フィルタとし、`pqmf_filter` で (遅延 m, β) を {(6, 9.0), (4, 7.0), (8, 10.0), (3, 5.0)} から選ぶ。帯域数は 2^pqmf_log2 × 2^pqmf_log2y (各 2〜16、合計 256 以下)。2 次元は分離型で、境界は循環拡張とする。

### 12.2 平面の方式選択

pqmf_log2 > 0 のとき、平面ごとに主ストリームで `bands` (bit) を送り、帯域方式か画素ブロック方式かを選ぶ。band_blocks 有効時、`bands` = 1 ならさらに `ll_split` (bit) を送る。

### 12.3 帯域ブロック符号化

各帯域画像を合成利得 (band_norm) で正規化した整数平面として、9〜11 のブロック符号化で符号化する。帯域 (k_x, k_y) の量子化ステップは Δ·(1 + 0.08·(k_x + k_y)) とする。左 (なければ上) の符号化済み帯域を鏡像補正したものを帯域間予測・文脈に用いる。インターでは予測画像の帯域を時間方向予測とする。`ll_split` = 1 のとき、LL 帯域を 2×2 の帯域に再分解し、同じ方式で再帰的に符号化する (§3.2 部分木分解)。

## 13 図形レイヤと辞書

### 13.1 図形

図形の種類はガウス、楕円、矩形、三角形とし、中心 (1/4 画素)、対数スケール l1, l2 (半径 2^(l/8))、回転 θ (2π/64 単位)、振幅、線形傾き (g_x, g_y)、エッジ幅 soft を持つ。図形は輝度に加算描画される (S += Σ 図形)。ブロック層は X − S を符号化し、最後に S を加える。

構文: 図形数 (uint)、各図形について次のいずれか。

- (インターで前フレームの同番号の図形がある場合) 時間方向フラグが 1: 前フレームの図形からの位置・振幅・傾きの差分 (図形の動き、§7.4)。
- それ以外: 「直前の図形と型・スケール・角度・soft が同一」フラグ、異なればそれらの値、続いて位置差分、振幅、傾き。

### 13.2 辞書

10.3 を参照。

## 14 ループ内フィルタ

平面ごとに次の順で適用する。各パラメータは主ストリームで送る。

1. **デブロック** (lf 有効時)
   - 8 画素格子上の 4 画素区間ごとに境界強度 bs を決める。イントラ系を含む境界は 2、残差のある境界は 1、輝度で動きが異なる境界 (方向・参照の相違、または MV 差 ≥ 4) は 1、それ以外は 0。
   - 閾値: β(q) は q ≤ 51 で HEVC の表、q > 51 で 64 + 2(q − 51)。tC(q) は q ≤ 53 で HEVC の表、q > 53 で round(24·2^((q−53)/6))。β にはオフセット beta_off、tC にはオフセット tc_off (いずれも sint、|·| ≤ 12) を加える。
   - 輝度: 境界両側のブロックが 16 画素以上で平坦な場合、長タップフィルタを適用する。両側の長さの小さい方が 64 以上なら n = 15、32 以上なら n = 7、16 以上なら n = 5。重みは f_i = (64·(2(n−i)−1) + n)/(2n)、修正量の上限は ⌊(tt_i·tC)/2⌋、tt_i = max(1, (6(n−i) + n/2)/n)。それ以外は HEVC 型の強/弱フィルタ。
   - 色差: bs ≥ 1 の境界で p0, q0 のみを修正する。
2. **周波数ゲインフィルタ** (lf_freq): 8×8 正弦窓 WOLA (ホップ 4) の DCT 係数に G = max(0, 1 − μσ²/c²) を掛ける。σ² = Δ²/12、μ = mu_q/4 (mu_q は uint、0 で無効)。
3. **画素ゲインマップ** (lf_map): 32×32 セルごとの γ (Q6、0〜128) を差分符号化し、出力 = 前段入力 + γ·(フィルタ後 − 前段入力)。
4. **CDEF** (cdef): 8×8 ブロックごとに 8 方向から方向を推定し、主フィルタ (強さ 0〜15) と ±45° の副フィルタ (強さ {0, 1, 2, 4}) を制約関数付きで適用する。平面ごとに最大 4 組の強さを送り、64×64 ブロックごとに組を選ぶ。
5. **ALF** (alf): 7×7 菱形フィルタ、12 クラス。

## 15 可逆層 (L1/L2)

- `lossy` = 0: 原画素を MED 予測で直接符号化する (完全可逆)。
- `l2` = 1: 非可逆の再構成 R に対し、残差 e = X − R を勾配と近傍残差の文脈で符号化し、X を完全に再構成する。

## 附属書 B (参考): 符号器の指針とプリセット

### B.1 RD 最適化

- λ = 0.57 · 2^((qp−12)/3) · 4^(bit_depth−8)。レートは CM モデルの現在の確率から −log2 p で見積もる。

- I フレーム (slow 以上) では TNS/IBC/辞書/MTS を外した符号化と D + λR を比べ、小さい方を採る。
